# IDA117V: South African water service delivery classification

Dataset: Statistics South Africa, General Household Survey 2023, household CSV supplied by the student. This package includes the uploaded data for local work; check Statistics South Africa's reuse terms before redistributing or publishing it.

## Install and execute

Python 3.10+ recommended.

```bash
python -m venv .venv
# Activate .venv according to your operating system
pip install -r requirements.txt
python train.py
streamlit run app.py
```

Training may take several minutes. The output folder contains five EDA charts, validation/test tables, model reports, confusion matrices, ROC plots, neural learning curves, ablations and an exact McNemar test. `models/` is generated by training and used by the app.

## Prediction question

Among GHS 2023 households with a yes/no response to `wat_inte_12mth`, classify whether the household reported a water interruption in the previous 12 months. 'Not applicable' is excluded rather than counted as 'No'. This is **retrospective classification**, not prediction of future outages.

## Method

60/20/20 stratified train/validation/test; one-hot preprocessing fitted on train only; dummy, logistic regression, random forest, MLP and residual tabular neural network; validation-led champion selection; tuning without test; three ablations; shared held-out test evaluation; exact binomial McNemar test. Target-adjacent interruption follow-ups are excluded. Other features may still be contemporaneous correlates and require cautious interpretation. All samples are treated as independent for this course demonstration; survey PSU clustering and weights are not modeled, so statistical uncertainty and generalizability are limited.

## Important caveats

Verify category meanings and codebook, licensing and lecturer approval before submission. Survey sample is not a service-fault registry. No household should be denied services based on predictions. Province and other demographic/context variables require fairness review. Models are not calibrated and not externally validated. Neural architecture is a residual tabular network; confirm lecturer accepts it as the second neural model.
